# easy-todo-minimax · PRD

> macOS 桌面便签，主打"随手贴、轻量、本地"。

## 1. 产品定位

一个桌面浮卡便签应用，参考小红书 / Apple Notes / 各种卡片便签 App。每个便签独立浮在桌面，标题/颜色/大小/置顶/类型都可调，本地存储，零云依赖。

## 2. v0.1 MVP 范围

### 2.1 4 种便签类型

| 类型 | 形态 | 关键元素 |
|------|------|---------|
| **文本** | 标题（可选）+ markdown 文本 | 字号调节、**实时渲染** markdown |
| **待办** | 标题 + checkbox 列表 | 子项增删、勾选、排序、已完成折叠 |
| **链接** | 标题 + 链接预览卡片 | 自动识别 URL、点击打开 |
| **图片** | 标题（可选）+ 图片 | 拖入 / 选文件 / 粘贴 |

### 2.2 6 个核心功能（P0）

1. **置顶** — 窗口 always-on-top，可切换
2. **窗口大小** — 边角 8 向 resize + 拖动
3. **便签标题** — 顶部 title 行，可空
4. **颜色更换** — 内置 8 色 pastel
5. **待办** — 独立便签类型
6. **贴图** = 图片便签

### 2.3 P1 候选（先不做）

- 全局快捷键 `Cmd+Opt+N` 新建便签
- 多便签搜索
- 导出 / 分享
- 开机自启
- 拖动换位 + 多选

## 3. 非目标

- ❌ Windows / Linux（v0.1 只 macOS）
- ❌ iCloud 同步
- ❌ 富文本所见即所得（用 markdown 编辑 + 预览替代，避开富文本编辑器 race 坑）
- ❌ 协作 / 多用户
- ❌ iOS / iPadOS

## 4. 设计决策锁（Q1–Q8）

| # | 决策点 | 锁定值 |
|---|--------|--------|
| Q1 | 窗口架构 | **多窗口**（一个便签一个独立 webview）|
| Q2 | 视觉质感 | **纯色 + 圆角 + 阴影**（参考图原样）|
| Q3 | 数据存储 | **本地 SQLite**（`~/Library/Application Support/com.easytodo.sticky/`）|
| Q4 | 全局快捷键 | **P0 不做**，进 P1 |
| Q5 | 字号调节 | **P0 要**（工具栏 A- / A+）|
| Q6 | 文本高亮 | **实时渲染 markdown**（隐藏 textarea + 渲染层覆盖，输入 300ms 防抖）|
| Q7 | Menu Bar 入口 | **P0 要**（驻留 + 新建 / 全部便签列表）|
| Q8 | 图片来源 | **拖入 + 选文件 + 粘贴**三种都要 |

## 5. 用户体验要点

- 打开 app 不弹主窗口，**直接在桌面浮现一个空白便签**作为起点
- 便签关闭 = 隐藏到 dock（不删除）；右键 Menu Bar 列表可彻底删除
- 创建便签默认 280×280、白色无标题、显示在屏幕中心偏上
- 颜色面板 8 色：黄 / 红 / 蓝 / 粉 / 绿 / 紫 / 橙 / 灰
- 拖动：title bar 区域；resize：便签四边 + 四角 8 个手柄
- 置顶状态视觉反馈：title bar 右侧一个小图钉图标（实心 = 置顶）

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 多 webview 内存占用（每个 ~30MB）| 控制默认尺寸，便签数量 < 20 个时无感 |
| 无边框窗口拖动 / resize 边界处理 | 套现成方案 `tauri-plugin-window-state` + 自定义 8 向 resize |
| 图片存文件 + DB 路径一致 | 存放在 App Support 子目录，删除便签时同步清理孤儿图片 |
| SQLite 多窗口并发 | 每个便签 webview 独立连接 Rust 端 service，service 内部用 Mutex 串行化 |
| markdown 渲染闪烁 | 预览模式不混入编辑，切换即重新挂载组件，避免增量 re-render |
